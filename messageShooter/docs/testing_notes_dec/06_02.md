# messageShooter component

This system holds campaigns, target lists and queues, and is the backbone of messageShooter. 
1) Campaigns: Define rules (day of week, time, frequency) for getting Contacts, Messages and Phone Tokens from @core. 
2) Target Lists: Organize recipients that will get receive messages based on "counter" and relationship tag.
3) Queues: Put campaigns' target lists into queues, which are processed by @queue_processor using @apiSocialHub and registering logs in @core/message_logs.  

Key Features:
1) 1x queue = 1x token
2) multiple queues can be processed at the same time with async calls
3) 8 second interval between target list recipients
4) sequential message order according to counter from logs
5) run_scheduler is the worker to trigger campaign rules
